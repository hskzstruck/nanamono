01 탭 메뉴란

탭 메뉴는 탭 버튼을 눌러 같은 자리의 내용을 바꿔 보는 기능이다.

시안에 있으면 초안을 요청할 때 같이 요청하고, 시안에 없고 나중에 추가하는 경우에는 초안을 만든 뒤에 요청해도 된다.

예시 — 탭을 눌러 보세요
공지사항 내용이다. 서비스 점검 일정과 업데이트 소식을 안내한다.
이벤트 내용이다. 진행 중인 할인과 사은품 행사를 안내한다.
자주 묻는 질문 내용이다. 결제와 배송에 대한 질문과 답변을 모아 둔다.

04 코드가 완성된 뒤: 변수 이름 정리

시안으로 만든 코드가 완성된 뒤, 마지막에 요청한다.

복사용
방금 만든 JS 코드에서 변수 이름만 바꿔줘. 다른 기능의 변수와 겹치지 않게 "해당 부분의 class 이름_역할" 형태로 지어줘. 예) tab_btn
기능, 디자인, HTML 태그 이름, class 이름은 그대로 두고 JS의 변수 이름만 바꿔줘.
