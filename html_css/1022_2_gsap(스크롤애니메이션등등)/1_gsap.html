GSAP 사용 가능 환경 만들기

GSAP CDN 연결하기

  1. GSAP 공식 사이트 접속(gsap 검색) https://gsap.com
  2. 상단 메뉴의 Docs 클릭
  3. 왼쪽 메뉴의

    Quick Start → Installation

    선택
  4. Installation 페이지에서 Install Helper 영역을 찾은 후, CDN 탭을 클릭.
  5. 사용할 플러그인을 선택. 플러그인을 쓰지 않을경우, 탭 아랫부분의 script src와 script부분을 복사.
    GSAP Core 기본 코드 예시
    <script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  document.addEventListener("DOMContentLoaded", (event) => {
    // gsap code here!
  });
</script>

    위 코드는 버전에 따라 변경될 수 있으므로, 이 문서의 해당 부분을 복사하여 사용하는 것보다 GSAP 공식 사이트의 Installation 페이지에서 최신 CDN 코드를 확인한 후 사용.

    gsap.to(), gsap.from(), gsap.fromTo(), timeline 등의 기능은 GSAP Core만 연결해도 사용할 수 있음.

    추가 기능이 필요한 경우에는 플러그인을 선택.

    ScrollTrigger, SplitText, Flip, Observer, Draggable,MotionPath 등등

    플러그인을 선택하면 코드 영역이 자동으로 변경되며, 선택한 플러그인에 필요한 script 태그가 함께 생성됨.
  6. 생성된 코드를 복사.
  7. HTML 문서의 </body> 태그 바로 위에 붙여넣는다.

GSAP 코드 수정 시 주의할 부분

GSAP 코드는 정해진 구조 안에서 필요한 값만 바꿔서 사용함. 아래 부분을 지우거나 빠뜨리면 코드가 동작하지 않을 수 있음.

기본 작성법

gsap.from("대상", {//css선택자를 따옴표 안에 작성
  변화 속성1,
  변화 속성2,
  duration: 1, // 애니메이션 실행시간(단위: 초)
  scrollTrigger: {
    스크롤트리거관련옵션1,
    스크롤트리거관련옵션2
  },// 해당 범위까지 스크롤트리거 관련 범위 지정임. 지워지지 않게 조심

  // 해당 요소에 추가 옵션을 넣을 경우
  // 바로 위 옵션 뒤에 쉼표(,)를 추가한 후 작성
  추가옵션1,
  추가옵션2
}); // 해당 요소에 GSAP 코드 적용 종료. 지워지지 않게 조심

// 다른 요소에 GSAP을 적용할 경우 여기에 새 코드 작성

작성 예

gsap.from(".fade-up", {
  y: 80,
  opacity: 0,
  duration: 0.8,
  scrollTrigger: {
    trigger: ".fade-up",
    start: "top 80%",
    markers: true
  }
});
1. 선택자 확인

".fade-up"처럼 애니메이션 대상은 큰따옴표 또는 작은따옴표 안에 작성함. 주로 클래스 선택자 많이 사용함

실제 HTML의 선택자와 GSAP 코드의 선택자가 같아야 함.

2. 중괄호, 소괄호 지워지지 않게 조심
3. 다음 옵션을 적을 때 쉼표 확인

마지막에 적힌 옵션 뒤 쉼표 추가 후 새로운 옵션 추가

자주 나는 오류: 클래스명 오타, 따옴표 삭제, 중괄호 누락, 쉼표 누락, 플러그인 CDN 연결 누락.

기본 애니메이션

gsap.to(), gsap.from(), gsap.fromTo() 의미

gsap.to()

현재 상태에서 지정한 상태로 변화하는 애니메이션 넣기. 내가 scritp에서 설정한 옵션이 최종 상태
변화한 후 모습을 지정. 

gsap.to(".box", {
  x: 200,
  opacity: 0.5,
  duration: 1
});

.box가 현재 위치(css로 지정한 위치)에서 오른쪽으로 200px 이동, opacity는 0.5로변경, 변화는1초동안 보여줌(애니메이션 실행시간)

gsap.from()

지정한 상태에서 시작해서 원래 상태로 돌아오며 애니메이션 됨.
변화하기 전 모습을 지정. 

gsap.from(".title", {
  y: 50,
  opacity: 0,
  duration: 1
});

.title이 아래로 50px, opacity는 0인 상태로 있다가, 1초 동안 원래의 위치로 돌아감.

gsap.fromTo()

시작 상태와 끝 상태를 모두 직접 지정함.

gsap.fromTo(".button",
  { opacity: 0, scale: 0.8 },
  { opacity: 1, scale: 1, duration: 0.7 }
);

.button이 처음에는 opacity가 0, scale은 0.8의 작은 상태이다가 0.7초동안 opacity가 1로 변하고 scale은 1로 변함

GSAP 기본 애니메이션에서 자주 사용하는 속성

속성 의미 예시
x 가로 방향 이동(+:오른쪽, -:왼쪽) x: 200, x:-200
y(+아래, -:위) 세로 방향 이동 y: 50, y:-50
opacity 투명도 조절 opacity: 0
scale 크기 확대/축소 scale: 1.2
rotation 회전 rotation: 360
duration 애니메이션 시간 duration: 1
delay 시작 전 대기 시간 delay: 0.3
ease 움직임 속도감 조절 ease: "power2.out"
기본 이동이나 등장 애니메이션에서는 x, y, opacity, duration을 가장 자주 사용함.

이 외에도 scale, rotation, delay, ease, repeat, yoyo, stagger, backgroundColor, borderRadius, width, height, left, top, filter, skewX, skewY, transformOrigin 등의 속성도 설정할 수 있음.

이동 방식 x/y? left/top?

left/top으로도 움직일 수 있지만, 해당 요소에 포지션이 들어가야 하므로, 단순 이동 애니메이션은 x/y를 우선 사용.

Timeline 기초

여러 애니메이션을 순서대로 실행할 때 timeline 사용.(애니메이션 플레이리스트)

[기본사용]

const tl = gsap.timeline();

tl.to(".logo", { y: -30, opacity: 0, duration: 0.5 })
  .to(".title", { y: 40, opacity: 0, duration: 0.7 })
  .to(".btn", { y: 20, opacity: 0, duration: 0.5 });

->.logo의 애니메이션이 끝나면 ,title의 애니메이션 시작, title의 애니메이션이 끝나면 .btn의 애니메이션 시작.

[겹쳐서 사용]

const tl = gsap.timeline();

tl.to(".logo", { y: -30, opacity: 0, duration: 0.5 })
  .to(".title", { y: 40, opacity: 0, duration: 0.7 }, "-=0.3")
  .to(".btn", { y: 20, opacity: 0, duration: 0.5 }, "-=0.3");

->.logo 시작 > .logo 애니메이션 끝나기 0.3초 전 .title 시작 > .title 애니메이션 끝나기 0.3초 전 .btn 시작

Stagger

stagger는 같은 움직임을 여러 요소에 순서대로 넣을 때 사용함.

gsap.from(".card", {
  y: 50,
  opacity: 0,
  duration: 0.7,
  stagger: 0.15
});
나란히 있는 card라는 같은 클래스를 가진 요소가 0.15초의 시간차를 두고 실행됨.

card card card card 이런 구조라면,

0.00초 첫번째 card 시작
0.15초 두번째 card 시작
0.30초 세번째 card 시작
0.45초 네번째 card 시작

ScrollTrigger 기초

스크롤 위치에 맞춰 애니메이션을 실행함.

ScrollTrigger 사용 전 확인

ScrollTrigger는 GSAP 기본 기능이 아닌 플러그인임.
따라서 GSAP Core CDN만 연결하면 동작하지 않으며, ScrollTrigger CDN을 추가로 연결해야 함. 그리고 script 가장 첫줄에 gsap.registerPlugin(ScrollTrigger);를 넣어야 함. 
<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/ScrollTrigger.min.js"></script>
//플러그인 js파일 cdn추가. 예시와 버전이 달라질 수 있으니 사이트에서 최신버전으로 가져오기
          
<script>
  gsap.registerPlugin(ScrollTrigger); //script가장 윗쪽에 추가
  gsap.from(".fade-up", {
    y: 80,
    opacity: 0,
    duration: 0.8,
    scrollTrigger: {
      trigger: ".fade-up",
      start: "top 80%",
      markers: true
    }
  });
</script>

핵심 옵션 설명

옵션 설명 예시
trigger 애니메이션을 발동시킬 요소 trigger: ".section"
start 트리거 시작 위치 (요소 기준 / 뷰포트 기준) start: "top 80%"
end 트리거 종료 위치 end: "bottom 20%"
markers 개발 중 시작/끝 선 표시 (배포 전 꼭 제거!) markers: true
toggleActions 진입/이탈 시 동작 설정 toggleActions: "play none none none"
pin trigger로 지정한 요소를 화면에 고정 pin: true
scrub 스크롤 위치를 애니메이션 진행률에 직접 연결 scrub: true

💡 start 값 읽는 법

start: "top 80%" = "요소의 top이 뷰포트 80% 지점에 도달하면 시작"

숫자가 클수록 더 일찍 발동됩니다. (100%는 화면 맨 아래)

pin, scrub이란?

pin: true

trigger로 지정한 요소를 스크롤해도 화면에 그대로 고정시킴. 정해진 구간(start~end) 동안만 고정되고, 구간이 끝나면 다시 스크롤을 따라 올라감.

scrub: true

스크롤 위치가 곧 애니메이션의 진행률이 됨. 스크롤을 내리면 애니메이션이 진행되고, 스크롤을 올리면 애니메이션도 거꾸로 진행됨. (재생 버튼을 누르는 개념이 아니라, 스크롤바 자체가 재생바가 되는 개념)

pin과 scrub은 같이 쓰는 경우가 많음.

pin으로 화면에 요소를 고정해두고, 그 고정된 구간 안에서 scrub으로 스크롤에 맞춰 애니메이션(크기, 위치, 투명도 등)을 서서히 변화시키는 방식. 
gsap.to(".text", {
  scale: 1.8, // 스크롤하는 동안 1배 -> 1.8배로 서서히 커짐
  scrollTrigger: {
    trigger: ".pin-wrap",
    start: "top top",
    end: "+=130%",
    pin: true,   // .pin-wrap을 화면에 고정
    scrub: true  // 스크롤 정도 = scale 변화 정도
  }
});
