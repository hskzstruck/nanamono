HOW IT WORKS

선은 원래 존재해요.

SVG의 stroke-dasharray와 stroke-dashoffset으로 선을 숨긴 다음, 스크롤한 만큼 드러내는 방식입니다. 그림 파일을 불러오는 대신 HTML 안에 SVG를 넣어서 각 선을 직접 제어했어요.

코드의 .draw_lines에서 색과 두께를, .drawing_section의 높이에서 스크롤 길이를 바꿔볼 수 있습니다.
