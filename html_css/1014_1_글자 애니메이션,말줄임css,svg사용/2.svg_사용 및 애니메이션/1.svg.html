01 SVG 개념과 원리

SVG는 이미지를 점이 아니라 "도형을 그리는 명령"으로 저장한 파일이다. JPG, PNG는 가로세로 점마다 색을 저장하기 때문에 확대하면 점이 보이고, SVG는 "여기에 원을 그려라"라는 명령을 저장해 두었다가 보여줄 때마다 새로 그리기 때문에 확대해도 선명하다. 확장자는 .svg이고, 메모장으로 열면 HTML과 비슷한 태그가 보인다. 

<svg width="100" height="100" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="#1a56db" />
</svg>
파란 원 하나
  • <svg> 도화지 역할. width height는 화면에 보이는 크기
  • viewBox="0 0 100 100" 도화지 안쪽 좌표를 가로 100 × 세로 100으로 잡는다는 뜻. 화면 크기를 바꿔도 비율대로 늘어나고 줄어듦
  • <circle> 원. cx cy는 중심 위치, r은 반지름, fill은 안쪽 색
확대했을 때 차이

왼쪽은 16×16 점으로 저장한 이미지를 120px로 늘린 것이고, 오른쪽은 같은 크기로 그린 SVG이다. 점으로 저장한 이미지는 계단 모양으로 깨지지만 SVG는 매끈하다. (왼쪽은 확대 차이를 보여주려고 코드로 만든 예시 이미지이다.)

02 색상 변경

SVG의 색은 fill(안쪽 색)과 stroke(선 색)로 정해진다. 색을 바꾸는 방법은 두 가지이다.

방법 ① SVG 코드 안의 값을 직접 수정
<!-- 파란 원 -->
<circle cx="50" cy="50" r="40" fill="#1a56db" />

<!-- fill 값만 바꾸면 빨간 원 -->
<circle cx="50" cy="50" r="40" fill="#e11d48" />
변경 전
변경 후
방법 ② 인라인 SVG에서 CSS로 변경
<svg class="circle_fill_css" width="100" height="100" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" />
</svg>

/* CSS */
.circle_fill_css { fill: #1a56db; }
.circle_fill_css:hover { fill: #e11d48; }
마우스를 올리면 색이 바뀐다
CSS로 색을 바꿨는데 안 바뀔 때

디자인 툴에서 뽑은 SVG는 도형 태그마다 fill="…"이 직접 박혀 있는 경우가 많다. 이 상태에서 바깥 <svg>에 CSS로 색을 주면 도형 자신의 값이 우선이라서 색이 바뀌지 않는다. 도형 태그의 fill 속성을 지우면 CSS가 적용된다. 

<!-- A : 도형에 fill이 박혀 있음 → hover해도 안 바뀜 -->
<svg class="icon_a" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="#1a56db" />
</svg>

<!-- B : fill 속성을 지움 → hover하면 바뀜 -->
<svg class="icon_b" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" />
</svg>

/* CSS */
.icon_a:hover, .icon_b:hover { fill: #e11d48; }
.icon_b { fill: #1a56db; }
A
안 바뀜
B
바뀜
currentColor — 글자색 따라가기

fill="currentColor"로 두면 부모 요소의 글자색(color)을 그대로 따라간다. 글자와 아이콘 색을 한 번에 맞출 때 쓴다. 

<span class="icon_text">
  <svg width="24" height="24" viewBox="0 0 100 100">
    <circle cx="50" cy="50" r="40" fill="currentColor" />
  </svg>
  메뉴 보기
</span>

/* CSS */
.icon_text { color: #1a56db; }
.icon_text:hover { color: #e11d48; }
메뉴 보기

03 img 태그 vs 코드로 넣기

SVG를 페이지에 넣는 방법은 크게 두 가지이다. 이미지처럼 <img> 태그로 불러오는 방법과, SVG 코드를 HTML 안에 직접 쓰는 방법(인라인)이다. 

<!-- 방법 A : img 태그 -->
<img class="compare_img" src="images/circle.svg" alt="파란 원">

<!-- 방법 B : 인라인 코드 -->
<svg class="compare_svg" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" />
</svg>

/* CSS */
.compare_img:hover { fill: #e11d48; }
.compare_svg { fill: #1a56db; }
.compare_svg:hover { fill: #e11d48; }
A. img
안 바뀜
B. 인라인
바뀜
마우스를 올려 비교
img 태그로 넣을 때
  • HTML이 깔끔하게 유지된다. 코드가 길어지지 않는다.
  • 파일로 따로 관리해서 교체가 쉽다. 파일만 바꾸면 모든 페이지에 반영된다.
  • 브라우저가 파일을 저장(캐시)해 두므로 여러 페이지에 같은 로고를 쓸 때 효율적이다.
  • width, alt 등 일반 이미지 속성을 그대로 쓴다.
코드(인라인)로 넣을 때
  • 페이지의 CSS가 SVG 안쪽까지 적용된다. hover 때 색을 바꿀 수 있다.
  • currentColor로 부모의 글자색을 따라가게 할 수 있다.
  • 페이지 CSS로 애니메이션을 자유롭게 제어할 수 있다.
  • 단점은 HTML이 길어지고, 같은 아이콘을 여러 번 쓰면 코드가 반복된다는 점이다.
💡 핵심 차이 한 줄 — img로 넣은 SVG는 "하나의 완성된 그림"으로 취급되어 페이지 CSS가 안쪽 도형에 닿지 않고, 인라인 SVG는 HTML의 일부라서 CSS가 닿는다.
구분 img 태그 인라인 코드
색 변경(CSS) 불가 가능
hover 효과 불가 가능
HTML 코드량 짧음 길어짐
교체·관리 파일만 교체 코드를 직접 수정
실무에서 쓰는 곳 로고, 일러스트 등 색이 안 바뀌는 이미지 hover 때 색이 바뀌는 아이콘
04 간단한 SVG 애니메이션

인라인 SVG의 도형에는 이미 알고 있는 CSS @keyframes 애니메이션을 그대로 쓸 수 있다. 새로 배울 문법은 없고, 도형 태그에 클래스를 주고 애니메이션을 연결하면 된다. 여기서는 원 하나, 사각형 하나로만 연습한다.

예시 1. 커졌다 작아지는 원
<svg width="100" height="100" viewBox="0 0 100 100">
  <circle class="circle_pulse" cx="50" cy="50" r="30" fill="#1a56db" />
</svg>

/* CSS */
.circle_pulse {
  transform-box: fill-box;
  transform-origin: center;
  animation: pulse 1.2s ease-in-out infinite;
}
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.4); }
}
예시 2. 빙글빙글 도는 사각형
<svg width="100" height="100" viewBox="0 0 100 100">
  <rect class="rect_spin" x="30" y="30" width="40" height="40" fill="#0e9f6e" />
</svg>

/* CSS */
.rect_spin {
  transform-box: fill-box;
  transform-origin: center;
  animation: spin 2s linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}
⚠️ SVG 도형에 transform을 쓸 때는 transform-box: fill-box;와 transform-origin: center;를 같이 써야 제자리에서 움직인다. 빼면 SVG 도화지의 왼쪽 위 모서리(0, 0)를 기준으로 움직여서 도형이 엉뚱한 곳으로 날아간다.
💡 위 코드는 인라인 SVG 기준이다. img 태그로 넣은 SVG는 페이지 CSS가 닿지 않으므로, 애니메이션을 쓰려면 SVG 파일 안에 직접 스타일을 넣어야 한다. 그래서 움직이는 SVG는 인라인으로 쓰는 것이 확실하다.

실무에서는 로딩 스피너, 버튼 아이콘의 작은 움직임, 강조용 점 깜빡임 같은 포인트 효과에 쓴다.
