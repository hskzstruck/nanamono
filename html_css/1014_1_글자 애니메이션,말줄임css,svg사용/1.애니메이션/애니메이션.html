01 애니메이션이란
@keyframes
  • 동작 시나리오를 적어두는 곳
  • "0%일 때는 여기, 100%일 때는 저기"를 정의
  • 시나리오에 이름을 붙여서 저장
  • 정의만 해서는 아무 일도 일어나지 않음
animation
  • 요소에 시나리오를 연결하는 속성
  • 시간, 반복 횟수 같은 재생 방식을 정함
  • 이름으로 @keyframes를 찾아서 재생
  • 적용하면 페이지가 열릴 때 바로 실행됨
💡 비유로 이해하기 — 영상 편집 프로그램에서 키프레임을 찍어 움직임을 만들어 본 적이 있다면 같은 개념이다. @keyframes는 "키프레임을 찍어둔 대본"이고, animation은 "재생 버튼 + 재생 옵션(속도, 반복 등)"이다.
가장 작은 애니메이션 코드
/* 1. 시나리오 만들기 — 이름은 move_box */ @keyframes move_box { from { transform: translateX(0); } to { transform: translateX(450px); } } /* 2. 요소에 연결하기 — 같은 이름 move_box를 적는다 */ .box_move { animation: move_box 2s ease-in-out infinite alternate; }
▶ 위 코드의 실행 결과
.box_move
⚠️ 두 곳의 이름이 똑같아야 연결된다. @keyframes 뒤의 이름과 animation에 적은 이름이 한 글자라도 다르면 아무것도 움직이지 않는다.
📖 코드 읽기용 안내 — 예제 안의 translateX() rotate() scale()은 transform 속성의 값이다. 각각 가로 이동 / 회전 / 크기 변경이라는 뜻만 알고 읽으면 된다. 이 자료는 animation 사용법에 집중하고, transform 값 자체는 자세히 다루지 않는다.
02 @keyframes 만들기
1
이름 정하기
@keyframes 바로 뒤에 시나리오 이름을 적는다. 나중에 animation에서 이 이름으로 부른다.
추천 영문 소문자 + 밑줄(snake_case) — move_box fade_up spin_round
비추천 띄어쓰기가 있거나 무슨 동작인지 알 수 없는 이름 — my box a1
2
단계가 2개면 from / to
시작과 끝만 있는 단순한 동작은 from(시작)과 to(끝)로 쓴다.
@keyframes slide_x { from { transform: translateX(0); } to { transform: translateX(450px); } }
3
단계가 여러 개면 퍼센트(%)
전체 동작 시간을 100%로 보고, 몇 %일 때 어떤 모습인지 적는다. from은 0%, to는 100%와 같은 뜻이다.
@keyframes slide_steps { 0% { transform: translateX(0) rotate(0deg); } 50% { transform: translateX(225px) rotate(180deg); } 100% { transform: translateX(450px) rotate(360deg); } }
▶ from / to 와 퍼센트 비교
from → to
0% → 50% → 100%
4
같은 모습은 쉼표로 묶기
"처음과 끝은 같고 중간만 다른" 동작은 0%, 100%를 한 번에 쓰면 짧아진다.
@keyframes float_y { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-14px); } }
✅ 0%(from)를 생략하면 요소가 원래 가지고 있던 값에서 시작한다. 그래서 "원래 모습 → 이렇게 변해라"만 쓰고 싶을 때는 to(또는 100%)만 적어도 된다.
🚫 @keyframes는 선택자 안에 넣지 않는다. .box { } 같은 중괄호 안이 아니라, CSS 파일 바깥(최상위)에 따로 적는다.
03 animation 속성 8가지
@keyframes를 요소에 연결하고 재생 방식을 정하는 속성들이다. 이름 그대로 "어떤 시나리오를 / 얼마나 걸려 / 어떻게 반복할지"를 하나씩 정한다.
속성하는 일자주 쓰는 값
animation-name재생할 @keyframes 이름move_box
animation-duration1회 재생 시간0.5s, 2s
animation-timing-function속도의 흐름linear, ease, ease-in-out
animation-delay시작 전 대기 시간0s, 0.2s
animation-iteration-count반복 횟수1, 3, infinite
animation-direction재생 방향normal, alternate
animation-fill-mode끝난 뒤 모습 유지 여부none, forwards, both
animation-play-state재생 / 일시정지running, paused
💡 이 중 name과 duration만 써도 움직인다. 나머지는 쓰지 않으면 기본값이 적용된다.
04 한 줄로 합쳐 쓰기 (축약형)
위 속성들은 보통 animation 한 줄에 합쳐서 쓴다. AI가 만든 코드에서도 대부분 이 형태로 나온다.
animation: 이름 시간 속도곡선 지연 반복횟수 방향 fill-mode 재생상태; /* 예시 */ animation: move_box 2s ease-in-out 0.5s infinite alternate forwards;
✅ 시간 값이 두 번 나오면 앞이 duration, 뒤가 delay다.
05 자주 쓰는 패턴 6가지
둥둥
① 둥둥 떠 있기 (float)
배너, 아이콘, 강조 카드에 많이 쓴다. 위아래로 천천히 반복.
@keyframes float_y { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-14px); } } .card_float { animation: float_y 2s ease-in-out infinite; }
LIVE
② 깜빡이기 (blink)
LIVE 표시, 알림 점처럼 주의를 끄는 용도.
@keyframes blink_fade { 0%, 100% { opacity: 1; } 50% { opacity: 0.2; } } .live_dot { animation: blink_fade 1s ease-in-out infinite; }
③ 계속 회전 (spin)
로딩 아이콘. 속도가 일정해야 자연스러워서 linear를 쓴다. 시작값(from)은 생략했다.
@keyframes spin_round { to { transform: rotate(360deg); } } .ring_spin { animation: spin_round 1s linear infinite; }
아래에서 쑥
④ 아래에서 떠오르며 등장 (fade up)
섹션 제목, 카드 등장 효과. 한 번만 재생하고 끝난 모습을 유지한다. 시작 전 대기 중에도 숨겨두려고 both를 썼다.
@keyframes fade_up { from { opacity: 0; transform: translateY(30px); } to { opacity: 1; transform: translateY(0); } } .card_fade_up { animation: fade_up 0.8s ease-out 0.2s both; }
⑤ 두근두근 커졌다 작아지기 (pulse)
버튼을 눌러보라고 유도하는 CTA 버튼에 쓴다.
@keyframes pulse_scale { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.2); } } .btn_pulse { animation: pulse_scale 1.5s ease-in-out infinite; }
스톱모션
⑥ 스톱모션 (양옆으로 살짝 흔들기)
부드럽게 이어지지 않고 "뚝, 뚝" 끊겨 보이는 손맛 있는 움직임. 속도 곡선을 steps(1)로 바꿔서 중간 과정을 없앤다.
@keyframes stop_wiggle { 0%, 100% { transform: rotate(-3deg); } 50% { transform: rotate(3deg); } } .card_stop { animation: stop_wiggle 0.8s steps(1) infinite; }
