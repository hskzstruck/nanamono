01 :root와 CSS 변수

CSS 변수는 자주 쓰는 값(색, 크기 등)에 이름을 붙여 저장해 두는 기능이고, :root는 그 변수들을 모아 선언하는 자리예요. :root는 <html> 태그를 가리키는 선택자라서, 여기에 선언한 변수는 페이지 어디서든 꺼내 쓸 수 있어요.

핵심 용어 정리
  • :root <html>을 가리키는 선택자. 변수를 모아두는 자리
  • --이름 내가 만드는 변수 이름. 앞에 --가 꼭 있어야 해요
  • var() 저장해둔 변수 값을 꺼내 쓰는 함수
02 변수 만들기 / 쓰기
1
:root 안에 변수 선언하기
--이름: 값; 형태로 적어요. --로 시작하면 "내가 직접 만든 이름"이라는 뜻이고, 이름은 snake_case(--main_color)로 지어요.
2
var()로 꺼내 쓰기
값을 쓰고 싶은 자리에 var(--이름)을 넣어요.
HTML
<!-- 결과 화면에 보이는 요소 --> <h2 class="title">제목</h2> <button class="button">버튼</button>
CSS
:root { --main_color: #1a56db; --box_radius: 10px; } .title { color: var(--main_color); } .button { background: var(--main_color); border-radius: var(--box_radius); }
결과 화면
제목

제목 글자색과 버튼 배경이 둘 다 --main_color 값을 가져다 쓰고 있어요.

03 왜 쓸까?

같은 값을 여러 곳에 쓸 때, 나중에 바꾸기 쉬워지기 때문이에요.

상황 변수 없이 :root 변수 사용
포인트 색을 #1a56db에서 #e11d48로 변경 파일 전체에서 #1a56db를 찾아 일일이 수정 (빼먹을 위험) :root의 한 줄만 수정
같은 색을 쓴 곳이 20군데 20군데 수정 1군데 수정
색 이름 파악 #1a56db가 뭔지 알기 어려움 --main_color로 의미가 보임
:root의 한 줄을 바꾸면
수정 전 : --main_color: #1a56db;
박스 1var(--main_color)
박스 2var(--main_color)
박스 3var(--main_color)
수정 후 : --main_color: #e11d48;
박스 1var(--main_color)
박스 2var(--main_color)
박스 3var(--main_color)
📝 이 자료의 <style> 맨 위에도 :root가 있어요. 크롬 개발자도구(F12)에서 <html>을 선택하고 Styles 패널의 --accent 값을 바꿔 보면, 자료 전체의 파란색이 한 번에 바뀌는 걸 볼 수 있어요.
04 어떤 값을 변수로 뺄까?

모든 값을 변수로 만들 필요는 없어요. 여러 곳에서 반복해서 쓰고, 나중에 바뀔 수 있는 값만 :root에 둬요.

변수로 빼는 값 변수 이름 예시 이유
브랜드 색, 글자색, 배경색 --main_color --text_color 전체 분위기를 바꿀 때 한 곳만 수정
폰트 종류 --main_font 폰트 교체가 한 줄로 끝남
모서리 둥글기, 그림자 --box_radius --box_shadow 카드·버튼의 모양을 통일
반복해서 쓰는 간격 --section_gap 섹션 간격을 한 번에 조절
✅ 한 번만 쓰는 값(예: 특정 박스 하나의 높이)은 변수로 만들지 않고 그냥 직접 적어요.
05 추가 설명 · 주의사항
알아두면 좋은 것들
  • :root와 html 선택자 둘 다 <html>을 가리키지만 :root가 우선순위(명시도)가 더 높아요. 변수 선언은 관례적으로 :root를 써요.
  • 다른 선택자 안에도 변수를 만들 수 있어요 .card { --card_bg: #fff; }처럼 선언하면 .card와 그 안쪽에서만 쓸 수 있어요. 사이트 전체에서 쓸 값만 :root에 둬요.
변수를 만들었는데 적용이 안 돼요 — 앞의 -- 를 빼먹지 않았나요?
틀림 main_color: red; → 일반 속성으로 인식돼서 무시돼요.
맞음 --main_color: red; → 이름 앞에 --를 꼭 붙여요.
꺼내 쓸 때 var() 없이 이름만 썼어요
틀림 color: --main_color;
맞음 color: var(--main_color); → 값 자리에는 var( )로 감싸야 해요.
변수 이름에 오타가 났어요
에러 메시지가 뜨지 않고 조용히 적용이 안 돼서 찾기 어려워요.
개발자도구 Styles 패널에서 해당 속성에 취소선이나 경고가 뜨는지 확인하고, 선언한 이름과 쓰는 이름이 똑같은지(대소문자 포함) 비교해요.
:root를 .root 또는 #root로 썼어요
틀림 .root / #root
맞음 :root → 점(.)이나 샵(#)이 아니라 콜론(:)이에요.
