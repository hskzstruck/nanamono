01 햄버거 메뉴란

햄버거 메뉴는 PC에서 가로로 펼쳐져 있던 메뉴가 태블릿·모바일 크기로 줄어들면 버튼 하나(☰)로 바뀌고, 누르면 메뉴가 열리는 기능이다.

헤더 구조와 반응형 레이아웃이 함께 바뀌므로, 페이지 초안을 요청할 때 같이 요청한다.

04 서브메뉴란

서브메뉴는 메뉴의 하위 메뉴를 보여 주는 기능이다. 보여 주는 방식에 따라 다섯 종류가 있다.
단순 드롭다운 : 올린 메뉴의 서브메뉴만 그 아래로 펼쳐진다. (예시: chunman.or.kr)
전체 드롭다운(풀다운) : 모든 메뉴의 서브메뉴가 한꺼번에 펼쳐진다. (예시: CJ온스타일)
메가메뉴 : 올린 메뉴의 내용만 가로 전체 폭 패널로 크게 펼쳐진다. (예시: 고용24)
풀스크린 메뉴 : 버튼을 누르면 화면 전체를 덮는 메뉴 화면이 열리고, 메뉴와 서브메뉴가 크게 보인다.
드로워 : 버튼을 누르면 화면 한쪽에서 서랍처럼 패널이 밀려 나오고, 그 안에 메뉴와 서브메뉴가 보인다. 모바일 햄버거 메뉴에 많이 쓴다.

풀다운과 메가메뉴는 혼용되기 쉬우므로, 프롬프트에 "모든 메뉴의 서브메뉴가 한꺼번에"(풀다운) 또는 "올린 메뉴의 서브메뉴만"(메가메뉴)을 꼭 적는다. 풀스크린 메뉴는 "화면 전체를 덮는", 드로워는 "한쪽에서 서랍처럼 밀려 나오는"을 꼭 적는다.

07 코드가 완성된 뒤: 변수 이름 정리

시안으로 만든 코드가 완성된 뒤, 마지막에 요청한다.

복사용
방금 만든 JS 코드에서 변수 이름만 바꿔줘. 다른 기능의 변수와 겹치지 않게 "해당 부분의 class 이름_역할" 형태로 지어줘. 예) hamburger_btn
기능, 디자인, HTML 태그 이름, class 이름은 그대로 두고 JS의 변수 이름만 바꿔줘.
