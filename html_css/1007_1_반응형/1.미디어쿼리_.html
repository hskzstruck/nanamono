미디어 쿼리(Media Query)

1. 반응형 사이트란?

반응형 사이트는 하나의 HTML 구조를 기준으로 화면 크기나 기기 환경에 따라 레이아웃, 글자 크기, 이미지 크기 등을 유동적으로 조정하는 웹사이트를 의미함. 사용자가 PC, 태블릿, 모바일 등 어떤 기기로 접속하더라도 화면에 맞게 보기 좋은 형태로 바뀌도록 제작함.

반응형 웹은 CSS의 상대 단위, 유동적인 레이아웃, 미디어 쿼리 등을 함께 사용해 다양한 화면에 대응하는 방식으로 구성함.

반응형 사이트와 적응형 사이트 비교

구분 반응형 사이트 적응형 사이트
특징 하나의 HTML 구조를 사용하고, CSS로 화면 크기에 따라 레이아웃을 유동적으로 변경함. PC용, 모바일용 등 화면별로 별도의 페이지나 레이아웃을 준비하는 방식임.
장점 하나의 구조를 유지하므로 관리가 비교적 쉽고, 다양한 화면 크기에 자연스럽게 대응하기 좋음. 기기별로 최적화된 화면을 따로 만들 수 있어 특정 환경에 맞춘 세밀한 구성이 가능함.
단점 화면 크기별 구조 변화를 미리 잘 설계하지 않으면 CSS가 복잡해질 수 있음. 기기별 페이지를 따로 관리해야 하므로 유지보수량이 많아질 수 있음.
사이트 예 Apple, Airbnb, GitHub, MDN Web Docs 네이버 모바일 페이지(m.naver.com), 일부 쇼핑몰 모바일 전용 페이지, 과거 m.도메인 사이트

2. 반응형을 위한 속성들

속성 / 단위 설명
rem 최상위 요소인 html의 글자 크기를 기준으로 계산되는 상대 단위임.
em 현재 요소 또는 부모 요소의 글자 크기를 기준으로 계산되는 상대 단위임.
% 부모 요소의 크기를 기준으로 계산되는 상대 단위임.
vw 브라우저 화면 너비를 기준으로 계산되는 단위임.
vh 브라우저 화면 높이를 기준으로 계산되는 단위임.
clamp() 최소값, 선호값, 최대값을 지정해 값이 일정 범위 안에서 유동적으로 변하도록 설정함.
min() 여러 값 중 가장 작은 값을 선택해 적용함.
max() 여러 값 중 가장 큰 값을 선택해 적용함.
min-width 요소가 더 이상 작아지지 않도록 최소 너비를 지정함.
max-width 요소가 너무 넓어지지 않도록 최대 너비를 지정함.
Grid의 minmax() CSS Grid에서 열 또는 행의 최소 크기와 최대 크기를 함께 지정함.
Grid의 auto-fit CSS Grid에서 들어갈 수 있는 만큼 열을 만들고, 남는 공간을 채우도록 열을 조정함.
Grid의 auto-fill CSS Grid에서 들어갈 수 있는 만큼 열을 만들고, 빈 열도 공간 계산에 포함함.
Media Query 화면 크기, 해상도, 기기 특성 등에 따라 다른 CSS를 적용하는 기능임.

3. 미디어 쿼리의 의미

특정 조건이 만족될 때만 CSS를 적용하는 규칙. 예를 들어 화면 너비가 특정 크기 이하이거나 이상일 때, 기존 CSS를 덮어써서 다른 레이아웃으로 변경할 수 있음.

기본 형식

@media (조건) {
    선택자 {
        조건이 만족될 때 적용할 CSS 스타일
    }
}

조건 : max-width 방식

max-width는 화면 너비가 지정한 값 이하일 때 적용됨. PC 화면을 먼저 만들고, 화면이 좁아질 때 태블릿이나 모바일 스타일을 덮어쓰는 방식에 자주 사용함. 

@media (max-width: 너비px) {
    선택자 {
        해당 너비 이하에서 덮어쓸 CSS 스타일
    }
}

조건 : min-width 방식

min-width는 화면 너비가 지정한 값 이상일 때 적용됨. 모바일 화면을 먼저 만들고, 화면이 넓어질 때 태블릿이나 PC 스타일을 추가하는 방식에 자주 사용함. 

@media (min-width: 너비px) {
    선택자 {
        해당 너비 이상에서 덮어쓸 CSS 스타일
    }
}

min-width와 max-width를 동시에 설정해 화면이 그 사이에 들어갔을때만 특정 css를 덮어쓸 수도 있다.

@media (min-width:최소너비px) and (max-width: 최대너비px){
    선택자 {
        화면이 크기가 최소 너비 안~ 최대너비 사이일때 덮어쓸 CSS 스타일
    }
}

코드 예시

.container {
    display: flex;
    gap: 20px;
}

.item {
    width: 50%;
}

@media (max-width: 768px) {
    .container {
        display: block;
    }

    .item {
        width: 100%;
    }
}

해석

  • 기본 화면에서는 .item이 가로로 2개 배치됨.
  • 화면 너비가 768px 이하가 되면 .container가 block 구조로 바뀜.
  • 각 .item은 width: 100%가 되어 세로로 쌓임.

4. 반응형 웹 제작 순서

브레이크 포인트는 어떻게 정하는가

브레이크 포인트는 특정 기기 이름만 기준으로 고정하기보다, 실제 레이아웃이 깨지는 지점을 기준으로 정하는 것이 좋음. 다만 기본 제작에서는 모바일, 태블릿, PC 정도의 기준을 먼저 잡고 시작하면 설명과 관리가 쉬움.

구분 예시 기준 사용 목적
모바일 ~ 767px 작은 화면에서 한 줄 배치, 메뉴 축약, 이미지 크기 조정 등을 적용함.
태블릿 768px ~ 1279px PC 구조를 일부 유지하되, 열 개수나 여백을 줄이는 데 사용함.
PC 1280px 이상 넓은 화면 기준의 기본 레이아웃을 구성함.
브레이크 포인트는 정답이 있는 값이 아니라, 콘텐츠가 보기 불편해지는 지점에 맞춰 정하는 기준값임.

max-width를 이용해 만드는 방식 : PC버전부터 코딩, 테블릿, 모바일 등에서 수정할 부분만 따로 미디어쿼리로 설정.

max-width 방식은 PC 화면을 먼저 작업한 뒤, 화면이 좁아지는 지점에서 태블릿과 모바일 스타일을 추가하는 방식. 기본 CSS는 PC 기준으로 작성하고, 미디어 쿼리에서는 태블릿과 모바일에서 달라지는 부분만 덮어쓰는 형태로 구성. 이미 PC 디자인이 먼저 정해져 있거나, 데스크톱 중심의 웹사이트를 제작할 때 사용하기 좋음.

  1. PC 완성 이미지를 보고 레이아웃을 먼저 작성함.
  2. pc완성 이미지와 테블릿 완성 이미지를 참고하여, pc에서 테블릿 레이아웃으로 변경할때 변화가 있는 부분을 max-width를 활용한 미디어 쿼리를 이용해 따로 설정함
  3. 테블릿 완성 이미지와 모바일 완성 이미지를 참고하여, 테블릿 화면에서 모바일 레이아웃으로 변경할때 변화가 있는 부분을 max-width를 이용한 미디어 쿼리를 이용해 따로 설정함
  4. 개발자 도구와 실제 기기에서 화면을 함께 확인함.
/* PC 기본 스타일 */
.list {
    display: flex;
    gap: 24px;
}

.list li {
    width: 25%;
}

/* 태블릿 768px 이상 ~ 1279px이하*/
@media (max-width: 1279px) {/*화면 크기가 1279px 이하일때 아래 속성을 덮어쓴다.*/
    .list {
        flex-wrap: wrap;
    }

    .list li {
        width: calc(50% - 12px);
    }
}

/* 모바일 ~767px 이하*/
@media (max-width: 767px) {/*화면 크기가 767px 이하일때 아래 속성을 덮어쓴다.*/
    .list {
        display: block;
    }

    .list li {
        width: 100%;
    }
}

min-width를 이용해 만드는 방식 : PC버전부터 코딩, 테블릿, 모바일 등에서 수정할 부분만 따로 미디어쿼리로 설정.

max-width 방식은 모바일 화면을 먼저 코딩 작업한 뒤, 화면이 넓어지며 자연스레 생기는 변화를 미디어쿼리를 이용해 코딩함. 기본 CSS는 모바일 기준으로 작성하고, 미디어 쿼리에서는 태블릿과 PC에서 달라지는 부분만 덮어쓰는 형태로 구성.

  1. 모바일 기준의 전체 레이아웃을 먼저 작성함.
  2. 테블릿 완성 이미지를 참고하여, 모바일 버전에서 테블릿 레이아웃으로 갈 때 변화가 있는 부분을 미디어 쿼리를 이용해 따로 설정함
  3. PC 완성 이미지를 참고하여, 테블릿 레이아웃에서 pc로 갈 때 변화가 있는 부분을 미디어 쿼리를 이용해 따로 설정함
  4. 개발자 도구와 실제 기기에서 화면을 함께 확인함.
/* 모바일 기본 스타일 */
.list{
    display: flex;
    gap: 24px;
    flex-direction:column;
}
.list li {
    padding:clamp(5px,3vw,20px);
    font-size: 14px;
}

/* 태블릿 768px 이상 ~ 1279px이하*/
@media (min-width: 768px) {/*화면 크기가 768px 이상일때 아래 속성을 덮어쓴다.*/
    .list {
        flex-direction:row;
        flex-wrap: wrap;
    }

    .list li {
        width: calc(50% - 12px);/*li가 한줄에 2개*/
    }
}

/* PC 1280px 이상일때*/
@media (min-width: 1280px) {/*화면 크기가 1280px 이상일때 아래 속성을 덮어쓴다.*/
    .list li {
        width: 25%;/*li가 한줄에 4개*/
        font-size: 16px;
    }
}

6. 반응형 웹 제작 시 주의사항

1) 고정 너비 사용 주의

요소에 width: 1200px처럼 고정 너비만 지정하면 작은 화면에서 가로 스크롤이 생길 수 있음. 이너 박스 제작시 max-width를 width대신 사용한다. 

.inner {
    max-width: 1200px;
    margin: 0 auto;
}

2) 이미지 크기 주의

이미지 부모의 크기가 반응형에서는 계속 변경되므로, 이미지가 부모 영역보다 커지지 않도록 max-width: 100%를 지정하는 것이 좋음.(혹은 width:100%라도 꼭 써줘야한다) 

img {
    max-width: 100%;
}

3) position 사용 시 주의

position: absolute를 많이 사용하면 화면 크기가 바뀔 때 요소가 겹치거나 위치가 어긋날 수 있음.
반응형 홈페이지의 경우 포지션을 최대한 넣지 않거나, 이미지 위에 올라가는 작은 요소 등 기준이 확실하게 있는 포지션을 쓰는것이 좋다.

4) 글자 크기와 여백 주의

모든 글자와 여백을 고정 px로만 지정하면 화면 크기에 따라 답답하거나 과하게 커 보일 수 있음.
rem, vw, clamp() 등을 적절히 사용해 유동적으로 조정하는 것이 좋음.

5) 개발자 도구 확인 시 주의

개발자 도구의 반응형 모드는 화면 크기를 빠르게 확인하기 좋지만, 실제 기기와 완전히 동일하지 않을 수 있음.
모바일 브라우저 주소창 높이, 터치 환경, 실제 폰트 렌더링 차이 등을 함께 고려해야 함.

6) 콘텐츠 기준으로 확인

반응형은 단순히 기기 크기만 맞추는 것이 아니라 콘텐츠가 읽기 좋고 사용하기 좋은 상태인지 확인하는 작업.
메뉴, 버튼, 표, 이미지, 긴 텍스트가 각 화면에서 자연스럽게 보이는지 확인하는 것이 중요함.
