01개발자도구란? / 여는 방법 / 위치 설정(도킹)

브라우저가 HTML/CSS를 어떻게 화면에 그렸는지 보고, 값을 바꿔 바로 확인하는 도구예요.

여는 방법 3가지
여는 방법 3가지
  • F12 가장 빠름
  • Ctrl + Shift + I
  • 화면에서 마우스 우클릭 → 검사 (우클릭한 요소가 바로 선택돼요)
개발자도구 위치 설정 (도킹)
Dock side 메뉴 열기 → 첫 번째 아이콘 선택으로 별도 창 분리
오른쪽 위 ⋮ 버튼 → Dock side에서 맨 왼쪽(첫 번째) 아이콘을 선택하면 별도 창으로 분리돼요. 경계선을 드래그하면 크기를 바꿔요.
예시 이미지 · Dock side 메뉴 열기 → 별도 창 아이콘 (실제 크롬 화면)

  • 1왼쪽 위 화살표 아이콘 — 화면에서 요소를 직접 클릭해서 고르는 버튼
  • 2기기 아이콘 — 모바일 화면 미리보기. 폰·태블릿 화면 크기로 미리 볼 수 있어요. (Ctrl + Shift + M)
  • 3왼쪽 영역 — HTML 구조. 클릭하면 파란색으로 선택돼요
  • 4오른쪽 영역 — 선택한 요소의 CSS (Styles / Computed)
  • 5파일명:줄 번호 — 이 CSS가 어느 파일 몇 번째 줄에 있는지 알려줘요. 클릭하면 Sources 탭에서 그 코드가 열려요.
  • 6⋮ 버튼 — 개발자도구 설정 메뉴예요. 여기서 Dock side(위치)를 바꿔요. (01번에서 설명)
실제 크롬 화면을 단순하게 본뜬 그림이에요. 크롬 버전에 따라 모양이 조금 달라요.
  • Styles — 이 요소에 적용된 CSS 규칙 목록. 값을 바로 고쳐볼 수 있어요.
  • Computed — 브라우저가 계산한 최종값과 박스 모델 그림.
