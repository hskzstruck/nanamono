03HTML 구조 읽기
예시 이미지 · HTML 구조 (h2를 선택한 상태)
▼<body>
1 ▼<div class="box">
3 <h2>제목</h2>
3 <p>설명</p>
2 ▶<ul> … </ul>
</div>
▶<footer> … </footer>
</body>
4html › body › div.box › h2
  • 1▼ (아래 삼각형) — 펼쳐져 있다는 뜻. 안에 자식 요소들이 보여요. 클릭하면 접혀요.
  • 2▶ (오른쪽 삼각형) — 접혀 있다는 뜻. 안에 자식이 있는데 …로 숨겨져 있어요. 클릭하면 펼쳐져요.
  • 3삼각형이 없는 줄 — 자식 요소가 없어요. 글자만 있거나(<h2>제목</h2>), <img>처럼 안이 비어 있는 태그예요.
  • 4맨 아래 경로 표시줄 — 선택한 요소의 부모를 따라 올라간 경로예요.

꺼진 상태 (회색)
켜진 상태 (파란색)

HTML 구조에서 태그를 클릭하면 화면에서 그 요소가 선택돼요. 얇은 요소를 고를 때 편해요.
05HTML 수정하기
  • 글자 / 속성 수정 — HTML 구조의 태그 안 텍스트나 class 같은 속성을 더블클릭하면, 복사하거나 수정할 수 있는 입력칸이 생겨요.
  • 삭제 / 숨기기 — 요소를 선택하고 Delete 키 = 삭제, H 키 = 숨기기(다시 누르면 보임)
  • 되돌리기 — Ctrl + Z. 새로고침하면 전부 원래대로 돌아가요.
06Styles 읽기 - 내가 쓴 CSS 중 일부만 안 먹을 때 참조

요소를 선택하면 Styles에 걸린 규칙이 모두 나와요. 같은 속성이 겹치면 하나만 적용되고 나머지엔 취소선이 그어져요. "내가 쓴 CSS인데 왜 안 먹지?"를 풀 때 가장 먼저 볼 곳이에요. (04. 요소 선택하기)

Styles 영역 읽는 법
예시 이미지 · Styles 영역 전체
element.style {1HTML에 직접 쓴 인라인 스타일 — 보통 가장 세요. 해당 요소 하나에만 직접 넣어주는 방식이에요.
}
#header .btn {2 style.css:20파일명:줄 번호 — 클릭하면 그 코드로 이동
background: blue;
}
.btn {style.css:12
background: red; 3취소선 — 덮어씌워져서 적용 안 됨
}
.btn {style.css:15
colr: red; 4노란 느낌표 — 오타 등으로 브라우저가 무시한 속성 (마우스를 올리면 이유가 나와요)
}
Inherited from body 5부모에게서 물려받은 스타일 (아래 "물려받은 값" 참고)
body {
font-size: 16px;
}
button {6 user agent stylesheet브라우저 기본 스타일 (가장 약해서 내 CSS가 쉽게 덮어요)
padding: 1px 6px;
}

1
CSS 코드 찾기
그림 2번의 파일명:줄 번호 확인 → VSCode에서 Ctrl + G → 줄 번호 입력
2
HTML 코드 찾기
HTML 구조의 class 이름·내용 일부를 복사(더블클릭) → VSCode에서 Ctrl + Shift + F로 전체 검색

위쪽 규칙이 아래쪽 규칙을 이겨요.

취소선·흐림 표시는 세 종류
1
덮어씌워진 경우 가장 흔함
더 센 규칙이 이미 같은 속성을 지정했어요. 해결: 이기는 규칙을 찾아 거기를 수정해요.
예시 이미지 · 덮어씌워짐
#header .btn {style.css:20
color: blue; ← 이김
}
.btn {style.css:12
color: red; ← 짐
}
2
잘못된 값 취소선 + 노란 ⚠
colr: red; 같은 오타나 width: 10xp; 같은 잘못된 값이에요. 해결: 철자를 확인해요.
예시 이미지 · 오타
.btn {style.css:15
colr: red;
}
3
효과 없는 속성 흐린 글씨 + ⓘ
문법은 맞지만 지금 상태에서는 효과가 없어요. 예: display: block인 요소의 justify-content. 해결: ⓘ에 마우스를 올려 툴팁을 읽고, 시키는 대로 같은 규칙에 display: flex(또는 grid)를 추가해요.
주의: 개발자도구는 모든 속성을 검사하지 않아서 ⓘ가 없어도 안 먹을 수 있어요. (예: align-items는 안 먹어도 흐려지지 않아요)
예시 이미지 · 효과 없음
.box {style.css:30
justify-content: center; ⓘ
}
물려받은 값 (Inherited from)

Inherited from ... 아래의 값은 부모(조상)에 쓴 CSS가 물려져 내려온 거예요. "안 썼는데 왜 이렇게 보이지?"의 출처를 찾는 곳이에요.

예시 이미지 · p 요소를 선택했을 때의 Styles
.desc {style.css:40
margin: 0;
}
1 Inherited from div.box
.box {style.css:30
color: #333;
font-size: 18px;
}
Inherited from body
body {style.css:5
font-family: "Noto Sans KR";
line-height: 1.7;
color: #000; 2
}
  • 1Inherited from 부모이름 — 이 아래 규칙은 부모가 정한 값이에요. 가까운 부모부터 먼 조상(body)까지 순서대로 나와요.
  • 2더 가까운 부모(.box)가 같은 속성을 정했기 때문에, 먼 조상(body)의 값은 취소선이 그어져요.
.box에 padding: 20px도 있다고 해도 여기에는 나오지 않아요. 상속되는 속성만 이 영역에 표시되기 때문이에요.
상속되는 속성 (글자 관련)
  • color font-size font-family
  • font-weight line-height text-align
  • 그래서 body에 한 번만 써두면 사이트 전체에 적용돼요.
  • 이 이외의 속성은 대부분 상속되지 않아요.
07Styles 수정하기

고친 내용은 화면에만 잠깐 적용돼요. 시험해 보고, 마음에 드는 값은 VSCode에 옮겨 적어요.

1
값 바꾸기 — 더블클릭 → 입력 → Enter
값을 더블클릭 → 입력 → Enter
예시 이미지 · 값 수정 중
.btn {
color: #fff;
padding: 8px 22px;
}
2
숫자 미세 조절 — ↑ ↓ 키
숫자 클릭 후 ↑ ↓ = 1씩, Shift+↑↓ = 10씩, Alt+↑↓ = 0.1씩
3
속성 끄고 켜기 — 체크박스
속성 왼쪽 체크박스를 해제하면 그 속성만 꺼져요.
예시 이미지 · 체크박스로 속성 끄기
.btn {
color: #fff;
border-radius: 6px;
}
체크가 해제된(꺼진) 속성은 화면에서 적용이 빠져요.
4
색상 바꾸기 — 색 칩 클릭
색상 값 옆의 네모 칩을 클릭하면 색상 선택창이 열려요. (스포이트로 화면 색도 뽑을 수 있어요)
예시 이미지 · 색 칩
.btn {
background: #1a56db;
}
네모 칩(파란색)을 클릭하면 색상 선택창이 나와요.
5
속성 추가 — 이미 있는 규칙(선택자)의 { } 안 빈 곳 클릭
규칙의 { } 안 마지막 속성 아래 빈 곳을 클릭 → 속성 이름 → Tab → 값. 자동완성이 떠요.
예시 이미지 · 어디를 클릭할까? (규칙 { } 안의 빈 곳)
1 .btn {style.css:12
color: #fff;
padding: 8px 22px;
2여기를 클릭
3 }
  • 1선택자 줄 — 어떤 요소에 적용되는 규칙인지 보여줘요. 이 규칙에 속성을 추가할 거예요.
  • 2클릭할 곳 — 마지막 속성 아래, 닫는 중괄호 위의 빈 공간이에요.
  • 3닫는 중괄호 } — 규칙의 끝이에요. 속성은 { 와 } 사이에 들어가요.
실제 화면에서는 빈 공간이 따로 표시되지 않아요. 마지막 속성 줄 오른쪽의 빈 곳이나 그 바로 아래를 누르면 돼요. 잘 안 눌리면 마지막 속성의 값을 클릭한 뒤 Tab을 눌러도 새 입력칸이 열려요.
예시 이미지 · 속성 추가 중
.btn {style.css:12
color: #fff;
padding: 8px 22px;
dis
display
…
}
dis까지만 쳐도 display가 후보로 나와요. 끝까지 다 안 쳐도 돼요.
6
새 규칙 추가 — 선택자가 없을 때 + 버튼
예시 이미지 · + 버튼과 새로 만들어진 규칙
Filter:hov.cls+
.btn {inspector-stylesheet:1
 
}
새 규칙은 inspector-stylesheet라는 임시 스타일시트에 만들어져요. 내 CSS 파일에는 저장되지 않으니, 필요하면 VSCode에서 직접 입력해야 해요.
해당 요소에 규칙이 없을 때 Styles 위쪽 + 버튼을 눌러요. 선택자가 자동으로 만들어져요. 마음에 들면 VSCode의 CSS에 직접 써야 해요.
7
:hov 버튼 — hover 상태 강제로 켜기
마우스를 올려야 보이는 :hover 스타일은 :hov 버튼에서 체크해 강제로 켜요.
예시 이미지 · :hov 버튼
Filter:hov.cls+
:hover   :active   :focus

09Console / Network
Console 탭 — 에러 확인

JS 에러가 빨간 글씨로 나와요. 오른쪽 파일명:줄 번호를 클릭하면 그 코드로 이동해요.

예시 이미지 · Console 탭
값 확인: 3script.js:2
✖ Uncaught ReferenceError: btn is not definedscript.js:5
첫 줄은 console.log() 결과, 둘째 줄은 에러예요. 에러 메시지의 파일명:줄 번호부터 확인해요.
Network 탭 — 파일이 제대로 불러와졌는지

파일 로딩 결과 목록이에요. Status가 빨간 404면 파일을 못 찾은 거라 경로·파일명을 확인해요. (F5로 새로고침해야 채워져요)

예시 이미지 · Network 탭
NameStatusType
index.html200document
style.css200stylesheet
logo.png404png
logo.png만 404 → 이미지 경로나 파일명을 다시 확인해요. (images 폴더 안에 있는지, 대소문자까지 같은지)
