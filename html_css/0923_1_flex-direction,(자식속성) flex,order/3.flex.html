flex 자식 속성 - flex-basis, flex-grow, flex-shrink

플렉스 아이템 크기를 결정하는 3가지 기준

  1. basis (기준): 변경 전 기준 크기
  2. grow (확장): 부모의 공간이 남을 때, 남는 공간을 누가 더 많이 가져갈지
  3. shrink (축소): 부모의 공간이 모자랄 때, 기준 크기(basis)를 바탕으로 누가 더 많이 줄어들지
기본값은 flex-grow: 0, flex-shrink: 1, flex-basis: auto
아이템의 원래 크기를 지키는 것이 원칙이나, 자리가 남을 때는 가만히 있고 자리가 모자랄 때만 유연하게 줄어드는 상태

flex-basis

  • 아이템의 시작 크기를 정한다
  • 기본값: auto — width/height가 있으면 그 값을, 없으면 콘텐츠 크기를 기준으로 함
  • 속성값: auto, 0, px, % 등
  • width와 함께 설정될 경우 flex-basis가 우선 적용됨

flex-grow

  • 남는 공간을 나누는 비율
  • 기본값: 0 — 남는 공간이 있어도 늘어나지 않음
  • 속성값: 0 이상의 숫자 (0, 0.5, 1, 2 등 / 음수 불가)

위 예제: 1번·3번은 grow:1, 2번은 grow:2 → 남는 공간을 1:2:1 비율로 분배

flex-shrink

  • 공간이 부족할 때 줄어드는 비율
  • 기본값: 1 — 공간이 부족하면 줄어듦 (0으로 설정하면 줄어들지 않음)
  • 속성값: 0 이상의 숫자 (0, 0.5, 1, 2 등 / 음수 불가)
  • grow와 달리 basis 크기가 클수록 더 많이 줄어드는 구조
    ex)완전히 같은 계산식은 아니나 체중을 뺄때, 10kg빼라가 아니라 네 체중의 10%를 빼라고 하는 느낌. 기준 체중이 본래 60kg이라면 6kg, 체중이 본래 100kg이라면 10kg을 빼야함.

flex (단축 속성)

flex-grow, flex-shrink, flex-basis를 한 번에 설정하는 단축 속성. 개별 속성보다 단축 속성 사용을 권장한다.

  • 속성값: grow shrink basis 순서로 작성 (예: flex: 1 1 0)
  • 키워드: flex: 1 (= 1 1 0), flex: none (= 0 0 auto), flex: auto (= 1 1 auto)

실무에서 많이 쓰는 패턴

1. flex: 1 — 균등 분배 (= flex: 1 1 0)

flex-grow는 남는 공간을 비율에 맞춰 분배하는 속성이나, basis가 0이면 자기 자신의 크기를 없이 부모의 크기를 균등하게 나눔. 탭, 균등 버튼 배열 등에 사용.

※ 특정 아이템에만 padding이나 min-width 등이 있으면 균등이 깨질 수 있다.

2. 고정 + 유동 레이아웃 (= flex: 0 0 Npx / flex: 1)

사이드바처럼 한쪽은 크기를 고정하고(예-flex:0 0 100px), 나머지가 남은 공간을 전부 채울 때(flex: 1) 사용.

한쪽은 이미지 박스(크기가 정해져있음), 나머지 공간은 글박스가 전부 차지하는 구조를 만들때

고정(flex:0 0 100px)
유동(flex: 1)
