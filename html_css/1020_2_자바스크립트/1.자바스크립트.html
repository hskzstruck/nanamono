JavaScript 기초

JavaScript는 웹 페이지에 동작을 추가하는 프로그래밍 언어이다.

HTML은 구조, CSS는 디자인, JavaScript는 사용자의 행동에 따라 화면을 바꾸는 역할을 한다.

1. JavaScript로 할 수 있는 일

  • 버튼을 클릭하면 메뉴 열기
  • 탭 버튼을 클릭하면 내용 변경하기
  • 팝업 열기 / 닫기
  • 스크롤 위치에 따라 헤더 디자인 변경하기
  • 특정 요소에 클래스를 추가하거나 제거하기
JavaScript는 화면을 직접 디자인하는 언어라기보다, HTML 요소와 CSS 클래스를 조작해서 화면의 상태를 바꾸는 데 많이 사용한다.

2. JavaScript 작성 위치

JavaScript는 HTML 문서 안에 직접 작성하거나, 외부 JavaScript 파일을 연결해서 사용할 수 있다.

HTML 안에 직접 작성

<script>
    console.log("안녕하세요");
</script>

외부 JavaScript 파일 연결

<script src="script.js"></script>
보통 script 태그는 body 태그가 끝나기 직전에 작성하는 경우가 많다. HTML 요소가 먼저 만들어진 뒤 JavaScript가 실행되도록 하기 위해서이다.

3. console.log()

console.log()는 개발자 도구의 콘솔 창에 값을 출력하는 코드이다.

화면에 직접 보이지는 않지만, 코드가 잘 실행되는지 확인할 때 자주 사용한다.

console.log("안녕하세요");
console.log(100);
브라우저에서 F12를 누른 뒤 Console 탭을 확인하면 출력 결과를 볼 수 있다.

4. 변수

변수는 값을 저장해두는 공간이다.

자주 사용하는 값이나 나중에 다시 사용할 값을 변수에 저장한다.

let userName = "홍길동";
let age = 20;

console.log(userName);
console.log(age);

값 변경하기

let num = 10;
num = 20;

console.log(num);
let은 값이 바뀔 수 있는 변수를 만들 때 사용한다.

5. const

const는 한 번 저장한 값을 다시 바꾸지 않을 때 사용한다.

HTML 요소를 선택해서 변수에 담을 때 자주 사용한다.

const button = document.querySelector(".btn");
웹 페이지에서 특정 요소를 선택해서 저장할 때는 const를 많이 사용한다.

6. 자료형

JavaScript에서 값은 종류에 따라 다르게 구분된다.

자료형 의미 예시
String 문자 "안녕하세요"
Number 숫자 100
Boolean 참 / 거짓 true / false 
let title = "JavaScript";
let count = 3;
let isOpen = true;

7. 연산자

숫자를 계산하거나 값을 비교할 때 연산자를 사용한다.

let a = 10;
let b = 5;

console.log(a + b); // 더하기
console.log(a - b); // 빼기
console.log(a * b); // 곱하기
console.log(a / b); // 나누기

비교 연산자

console.log(a > b);
console.log(a < b);
console.log(a === b);
비교 연산자의 결과는 true 또는 false로 나온다.

8. HTML 요소 선택하기

JavaScript로 HTML 요소를 조작하려면 먼저 해당 요소를 선택해야 한다.

하나만 선택하기

const button = document.querySelector(".btn");

여러 개 선택하기

const items = document.querySelectorAll(".item");
CSS 선택자와 같은 방식으로 작성한다. 클래스는 .btn, 아이디는 #header처럼 작성한다.

9. 이벤트

이벤트는 사용자의 행동을 의미한다. 클릭, 마우스 올림, 마우스 나감, 스크롤 등이 이벤트에 해당한다.

addEventListener는 "지정한 행동이 일어나면 지정한 함수를 실행해라"는 뜻

클릭 이벤트

button.addEventListener("click", function(){
    console.log("버튼 클릭");
});

마우스 올림 이벤트

box.addEventListener("mouseenter", function(){
    console.log("마우스 올림");
});

마우스 나감 이벤트

box.addEventListener("mouseleave", function(){
    console.log("마우스 나감");
});

10. classList

classList는 HTML 요소의 클래스를 추가, 제거, 전환할 때 사용한다.

실제 웹 제작에서는 JavaScript로 스타일을 직접 많이 바꾸기보다, CSS 클래스를 추가하거나 제거하는 방식이 많이 사용된다.

클래스 추가

box.classList.add("active");

클래스 제거

box.classList.remove("active");

클래스 전환

box.classList.toggle("active");
toggle은 active 클래스가 없으면 추가하고, 있으면 제거한다.

11. 조건문

조건문은 특정 조건이 맞을 때만 코드를 실행한다.

let num = 15;

if(num > 10){
    console.log("10보다 큼");
}

if / else

let score = 80;

if(score >= 60){
    console.log("통과");
}else{
    console.log("다시 확인");
}

화면 너비 조건

if(window.innerWidth < 768){
    console.log("모바일 화면");
}

12. 반복문 forEach

여러 개의 요소에 같은 작업을 반복할 때 forEach를 사용한다.

탭 버튼, 메뉴 버튼, 여러 개의 카드에 이벤트를 줄 때 자주 사용한다.

const buttons = document.querySelectorAll(".tab-btn");

buttons.forEach(function(button){
    button.addEventListener("click", function(){
        console.log("탭 클릭");
    });
});
querySelectorAll로 여러 요소를 선택한 경우, 각각의 요소에 이벤트를 주려면 forEach를 함께 사용하는 경우가 많다.

13. 함수

함수는 코드를 묶어두고 필요할 때 실행하는 방법이다.

function openMenu(){
    console.log("메뉴 열기");
}

openMenu();

이벤트 안에서 함수 실행하기

button.addEventListener("click", function(){
    openMenu();
});
같은 코드를 여러 번 사용해야 할 때 함수로 만들어두면 관리하기 쉽다.

14. DOMContentLoaded

DOMContentLoaded는 HTML 문서를 모두 읽은 뒤 JavaScript를 실행하게 하는 이벤트이다.

document.addEventListener("DOMContentLoaded", function(){
    const button = document.querySelector(".btn");
});
script 파일을 head 안에 연결했는데 선택자를 찾지 못하는 경우, DOMContentLoaded를 사용하면 도움이 된다.

15. 자주 사용하는 값과 속성

코드 의미

16. HTML 구조 추가하기

JavaScript는 기존 HTML 안에 새로운 HTML 구조를 추가할 수 있다.

버튼을 클릭했을 때 목록, 카드, 공지사항, 댓글 같은 구조를 화면에 새로 넣을 때 사용할 수 있다.

기본 HTML 구조

<button class="add-btn">내용 추가</button>
<div class="list">
    <p>기존 내용</p>
</div>

insertAdjacentHTML()

insertAdjacentHTML()은 선택한 요소의 특정 위치에 HTML 문자열을 추가하는 메서드이다.

const addBtn = document.querySelector(".add-btn");
const list = document.querySelector(".list");

addBtn.addEventListener("click", function(){
    list.insertAdjacentHTML("beforeend", "<p>새로운 내용</p>");
});
버튼을 클릭하면 .list 안쪽의 마지막 위치에 <p>새로운 내용</p> 구조가 추가된다.

추가 위치

값 추가되는 위치
beforebegin 선택한 요소의 앞
afterbegin 선택한 요소 안쪽의 맨 앞
beforeend 선택한 요소 안쪽의 맨 뒤
afterend 선택한 요소의 뒤

beforeend 위치 이해하기

<div class="list">
    <p>기존 내용</p>

    여기에 새로운 HTML이 추가됨
</div>

여러 줄의 HTML 구조 추가하기

추가할 구조가 길 때는 백틱(`)을 사용하면 여러 줄로 작성할 수 있다.

const addBtn = document.querySelector(".add-btn");
const list = document.querySelector(".list");

addBtn.addEventListener("click", function(){
    list.insertAdjacentHTML("beforeend", `
        <div class="item">
            <h3>새로운 제목</h3>
            <p>새로운 내용입니다.</p>
        </div>
    `);
});

실무 예시 : 공지사항 추가

<ul class="notice-list">
    <li><a href="#">기존 공지사항</a></li>
</ul>
<button class="notice-btn">공지 추가</button>
const noticeBtn = document.querySelector(".notice-btn");
const noticeList = document.querySelector(".notice-list");

noticeBtn.addEventListener("click", function(){
    noticeList.insertAdjacentHTML("beforeend", `
        <li>
            <a href="#">새로운 공지사항</a>
        </li>
    `);
});
슬라이드 아이템, 카드 목록, 게시물, 댓글처럼 같은 구조가 반복해서 추가되는 경우에 활용할 수 있다.

17. 자주 발생하는 오류

오류 상황 확인할 내용
클릭해도 동작하지 않음 선택자 이름이 HTML 클래스명과 같은지 확인
Cannot read properties of null 오류 선택한 요소가 실제 HTML에 있는지 확인
클래스가 추가되지 않음 classList.add() 안의 클래스 이름 오타 확인
여러 개 중 하나만 동작함 querySelector와 querySelectorAll의 차이 확인
코드 전체가 실행되지 않음 괄호, 중괄호, 따옴표, 세미콜론 위치 확인
