개발자 도구 2

준비: Live Server로 사이트를 열고 F12로 개발자도구를 켠다. 브라우저 창은 최대화한다(폭 1920px 기준). VSCode에서 같은 폴더를 연다. DevTools에서 확인·수정한 내용은 VSCode의 CSS와 HTML, JS에도 반영한다.

1
브라우저 탭에 BIJOUPOP 파비콘(images/favicon.png)이 나오게 하려고 했는데, 실제로는 안 나온다. 파비콘을 연결한다.
2
스타일 파일(css/style.css)을 연결해서 사이트 디자인이 적용되게 하려고 했는데, 실제로는 스타일이 하나도 적용되지 않았다. 원인을 파악하고 CSS 파일을 연결한다.
3
페이지 전체 글꼴을 눈누의 프리텐다드(Pretendard) 웹폰트로 하려고 body에 font-family: "Pretendard"를 넣었는데, 실제로는 프리텐다드가 아닌 다른 글꼴로 구현되었다. 원인을 파악하고 웹폰트를 연결한다.
4
헤더와 각 섹션의 내용을 가운데 정렬하는 박스(.inner)의 너비를 1540px로 하려고 했는데, 실제로는 1200px로 구현되었다. 1540px로 변경한다.
5
헤더의 로고(BIJOUPOP) 글자 크기를 34px로 하려고 했는데, 실제로는 28px로 구현되었다. 원인을 파악하고 수정한다.
6
상단 메뉴에 마우스를 올렸을 때 글자색을 #6a1bd8로 하려고 했는데, 실제로는 #8f55e6로 구현되었다. #6a1bd8로 변경한다.
7
맨 위 메인 비주얼(슬라이드)은 가운데 정렬 박스 없이 화면 전체 폭으로 나오도록 하려고 했는데, 실제로는 가운데 정렬 박스 안에 들어가 양옆 슬라이드가 잘려 보인다. 원인을 파악하고 수정한다.
8
상품 카드의 할인율(예: 25%) 글자색을 보라색 #6a0dd8로 하려고 color: #6a0dd8을 넣었는데, 실제로는 보라색이 적용되지 않았다. 원인을 파악하고 수정한다.
9
화면 폭이 600px 이하일 때 상품 목록이 한 줄에 1개씩 나오도록 @media (max-width: 600px)로 하려고 했는데, 실제로는 400px 이하에서 바뀌는 것으로 구현되었다. 600px로 변경한다.
10
NEW ITEM의 NEW 태그를 모두 검정 배경·흰 글씨로 하려고 했는데, 실제로는 세 번째 상품의 태그만 회색 배경·진회색 글씨로 구현되었다. 원인을 파악하고 수정한다.
11
WEEKLY BEST 탭 버튼(목걸이, 귀걸이 등)의 좌우 안쪽 여백을 13px로 하려고 했는데, 실제로는 버튼 안쪽 여백이 없고 버튼 사이 바깥 간격만 넓게 구현되었다. 원인을 파악하고 수정한다.
12
에디토리얼 영역의 두 번째 큰 이미지(images/ed/e2.jpg)가 나오게 하려고 했는데, 실제로는 이미지 자리가 회색 빈 박스로 보인다. 원인을 파악하고 수정한다.
13
에디토리얼 제목 영역(Luxury Jewelry 등)에서 설명 글과 아래 구분선 사이의 안쪽 여백을 33px로 하려고 했는데, 실제로는 3px로 구현되었다. 33px로 변경한다.
14
인스타그램 이미지를 한 줄에 8개씩 나오도록 하려고 했는데, 실제로는 한 줄에 6개씩 나온다. 한 줄에 8개씩 나오도록 수정한다.
15
리뷰 페이지 번호(‹ 1 2 3 … ›)를 가운데 정렬하려고 justify-content: center를 넣었는데, 실제로는 왼쪽에 붙어서 나온다. 원인을 파악하고 수정한다.
16
푸터 안내 링크(회사소개, 이용약관 등)의 글자색을 #777로 하려고 했는데, 실제로는 #333으로 구현되었다. #777로 변경한다.
