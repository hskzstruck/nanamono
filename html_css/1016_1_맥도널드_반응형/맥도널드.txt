글씨 크기: 1rem
줄간격 : 1.3

미디어쿼리 기준 : 1099px이하, 태블릿
599px이하, 모바일

[제작 시 참고사항]

1. CSS 변수 사용

사이트에서 반복적으로 사용하는 주요 색상은 CSS 변수로 지정하여 사용함.

<현재 사용된 주요 색상>

- #db0007 : 메인 브랜드 색상(맥도날드 레드)
- #ffbc0d : 포인트 색상(맥도날드 옐로우)
- #111111 : 기본 글자 색상
- #ffffff : 배경 및 카드 색상
- #efefef : 섹션 배경색
- #333333 : 푸터 배경색
- #999999 : 푸터 글자색

2. 콘텐츠 최대 너비 : 1100px(max-width:1100px)


3. 각 섹션 제목 크기
메인 제목은 clamp()를 사용하여 제작함.
- 최소 크기 : 25px
- 화면 크기에 따라 약 3.5vw 비율로 확대 및  축소
- 최대 크기 : 50px

4. 섹션 상하 여백
섹션 간 여백(위아래)은 clamp()를 사용하여 제작함.
- 최소 여백 : 50px
- 화면 크기에 따라 약 8vw 비율로 확대
- 최대 여백 : 100px



5. Swiper 메인 배너
메인 배너는 Swiper를 사용하여 제작함.(autoplay 데모로 가져오기)

적용 기능
- 자동 재생
- 이전 / 다음 버튼
- 페이지네이션
- 무한 반복(loop)

6. 모바일 메뉴 제작(hamber.js 파일 연결해서 수정해서 사용하기)
JavaScript는 active 클래스 추가/제거만 담당함.

메뉴 열기 → active 추가
메뉴 닫기 → active 제거

실제 위치 이동 및 애니메이션은 CSS에서 처리함.
유지보수가 쉽고 수정이 편함.

7. 모바일 메뉴 크기
모바일 메뉴는 화면 오른쪽에서 등장하도록 제작함.(애니메이션 들어가게 제작하세요~!)
- 메뉴 너비 : 화면 너비의 50%
기기 크기가 변경되어도 메뉴 크기가 함께 변경되도록 제작함.


8. Grid 사용
상품 메뉴는 Grid를 사용하여 제작함.
