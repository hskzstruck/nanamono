이 파일에서 부모의 이름은 클래스 .box로 통일

[부모에게 주는 속성]

grid-template-columns

repeat 반응형 응용

① minmax()

최소 크기와 최대 크기를 지정한다.

minmax(최소크기, 최대크기)
.box {
    display: grid;
    grid-template-columns: repeat(3, minmax(250px, 1fr));
    /*최소 250px, 최대 1fr 크기를 가지는 열을 3개 만든다.
    부모 공간이 충분하면 3개의 열이 남은 공간을 1:1:1 비율로 나눠 가진다. 하지만 부모 공간이 좁아져도 각 열은 250px보다 작아지지 않기 때문에,
    3열의 최소 너비 합인 750px보다 부모가 작아지면 그리드가 넘칠 수 있다.*/
    gap: 20px; }

② auto-fit

화면 크기에 맞춰 들어갈 수 있는 만큼 열을 자동 생성한다.

.box {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    /*보통 repeat(), minmax()와 함께 이 형태로 사용. 화면 크기에 따라 열 개수를 자동으로 조절할 때 사용한다.*/
    gap: 20px;
}

③ auto-fill

auto-fit과 비슷하지만 빈 칸의 공간을 유지한다.

.box {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
    /*보통 repeat(), minmax()와 함께 사용하여 화면 크기에 따라 열 개수를 자동으로 조절할 때 사용.
    gap: 20px;
}
