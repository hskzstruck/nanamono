box(grid container)

이 파일에서 부모의 이름은 클래스 .box로 통일

[부모에게 주는 속성]

1. display:grid

부모 요소에 지정하여, Grid 레이아웃을 시작한다. 이 속성만 지정했을 때 가로 정렬이 저절로 되지 않아, grid-template-columns 등 다른 속성을 함께 써야 한다.

.box {
    display: grid;
}

2. grid-template-columns

가로 열의 개수와 크기를 지정한다.(가로로 몇개의 칸이 들어갈지 정함)

기본 사용법 : 값의 개수 = 열의 개수
.box {
    display: grid;
    grid-template-columns: 첫번째열너비 두번째열너비 세번째열너비;
}

grid-template-columns 속성값

①fr (Fraction)

Grid에서 남은 공간을 비율로 나누는 단위. gap과 고정너비열(px로 설정된 열)를 먼저 계산한 뒤 남은 공간을 비율로 나눈다.

.box {
    display: grid;
    grid-template-columns:500px 1fr 1fr;
    gap: 50px;
}

* 고정너비열 500px과 gap 50px을 제외한 남은 공간을 비율대로 나눠가짐.

이미지 영역 500px

.box {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
}

② repeat()

같은 크기의 열을 반복해서 만든다.

.box {
    display: grid;
    grid-template-columns: repeat(반복횟수, 반복할값);;
}
.box {
    display: grid;
    grid-template-columns: repeat(4, 1fr);/*4개 열을 1:1:1:1 비율로 설정. grid-template-columns:1fr 1fr 1fr 1fr과 같은뜻.*/
    gap: 20px;
}

3. gap

아이템 사이 간격을 지정한다. 플렉스에서 사용했을때와 같은역할

자식에게 주는 속성

1. grid-column

그리드 아이템이 가로(열)를 몇 칸 차지할지 지정

.item{
    grid-column: span 숫자; /*특정 아이템이 가로로 지정한 칸만큼 차지하게 한다.*/
    grid-column: 시작 위치(라인 번호);
    grid-column: 시작라인 / 끝라인;
}

span 숫자 : 특정 아이템이 지정한 숫자 칸만큼 차지하게 한다.

.box {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 20px; }
.item-big {
    grid-column: span 2;
}

② grid-row

그리드 아이템이 세로(행)를 몇 칸 차지할지 지정

.item{
    grid-row: span 숫자; /*특정 아이템이 가로로 지정한 칸만큼 차지하게 한다.*/
    grid-row: 시작 위치(라인 번호);
    grid-row: 시작라인 / 끝라인;
}

span 숫자 : 특정 아이템이 지정한 숫자 칸만큼 차지하게 한다.

.box {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    grid-auto-rows: 80px;
    gap: 20px;
}
.item-tall {
    grid-row: span 2;
}
