속성 속성값 설명 예시

align-items

center 셀 세로 가운데 정렬
baseline 텍스트 기준선에 맞춤

grid-auto-rows

grid-auto-columns

1fr 남은 공간 비율로 분배
minmax(80px, 1fr) 최소 80px, 최대는 비율
grid-template-columns로 정의되지 않은 열의 너비를 지정
justify-content
start 왼쪽 정렬
end 오른쪽 정렬
center 가로 가운데 정렬
stretch 컨테이너 너비를 꽉 채움

자식에게 주는 속성

사용 빈도가 비교적 높은 속성을 위쪽에 배치했다.

속성 속성값 설명 예시
justify-self
start 셀의 왼쪽에 정렬
end 셀의 오른쪽에 정렬
center 셀의 가운데 정렬
stretch 셀 너비를 채움
해당 아이템만 가로 방향으로 정렬
align-self
start 셀의 위쪽에 정렬
end 셀의 아래쪽에 정렬
center 셀의 세로 가운데 정렬
stretch 셀 높이를 채움
해당 아이템만 세로 방향으로 정렬
place-self
center 가로·세로 모두 가운데 정렬
start center 세로 시작 / 가로 가운데
end center 세로 끝 / 가로 가운데
stretch 가로·세로 모두 채움
해당 아이템만 가로·세로 방향으로 정렬
grid-area
header header 영역에 배치
side side 영역에 배치
main main 영역에 배치
grid-template-areas에서 지정한 영역 이름을 적용
header
side
main
grid-column-start/end

span 2 현재 위치에서 2칸 차지

1 / -1 모든 행 차지
세로 방향의 시작선과 끝선을 지정
