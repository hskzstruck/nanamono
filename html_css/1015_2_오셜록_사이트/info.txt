[크기 정보]
- 기본 글자 크기는 1rem 사용 (브라우저 기본값 기준 16px)
- 메뉴 글자 크기는 1.125rem 사용 (약 18px)
- 작은 제목은 0.875rem 사용 (약 14px)
- 큰 제목은 clamp(30px, 4vw, 40px) 사용
- 큰 제목은  30px 이하로 줄어들지 않고 40px 이상 커지지 않음
- 본문 글자는 clamp(15px, 2vw, 18px) 사용
- 본문 글자는 화면 크기에 따라 유동적으로 변경되며 15px 이하로 줄어들지 않고 18px 이상 커지지 않음
- 섹션 상하 여백은 clamp(50px, 8vw, 100px) 사용
- 화면 크기에 따라 50px ~ 100px 범위 내에서 자동 조절
- 섹션 제목 아래 여백은 clamp(20px, 4vw, 50px) 사용
- 기본 요소 간격은 clamp(14px, 2vw, 20px) 사용
- 중간 크기 여백은 clamp(16px, 2.5vw, 30px) 사용
- 상품 영역 간격은 clamp(10px, 2vw, 20px) 사용
- ABOUT 영역의 텍스트 상단 여백은 clamp(0px, 8vw, 150px) 사용
- 제목의 자간은 clamp(10px, 2vw, 20px) 사용
- SHOP 영역은 Grid를 사용하여 상품 목록을 배치
- 메인배너 높이는 70vh 사용
- 메인배너 이미지는 object-fit:cover 사용
- 메인배너 이미지는 object-position:20% 사용
- 태블릿에서는 ABOUT 영역이 세로 배치로 변경됨
- 모바일에서는 상품 목록이 1열로 변경됨
- 모바일에서는 햄버거 메뉴 버튼 표시
- 햄버거 버튼 클릭 시 오른쪽에서 왼쪽으로 메뉴 패널 등장
- 메뉴 패널은 화면 너비의 50% 사용
- 메뉴 패널은 흰색 배경 사용
- X 버튼 클릭 시 오른쪽으로 이동하며 닫힘
- 메뉴 등장 및 닫힘 애니메이션은 transform + transition 사용
- JavaScript는 active 클래스 추가 및 제거 용도로 사용
- CSS에서는 active 클래스가 적용되었을 때 transform 값을 변경하여 메뉴를 표시
- 파비콘 설정 (favicon.ico)
