테이블 css로 꾸미기

  • border 속성은, html에 넣지 않고! 각 셀에게 지정.
    th, td{border:1px solid #000;}
  • cellpadding은 padding으로 대체.
    th, td{padding:10px;}
  • cellspacing은 47p 아랫부분 참조.
    table{border-collapse:collapse;}
  • align은 오른쪽 정렬은 table{margin-left:auto}
    가운데 정렬을 table{margin:0 auto;}
    셀 안의 글씨의 정렬은 text-align속성을 사용한다.(47p 윗부분)
  • width/height는 각 셀에게 필요한만큼 지정할 수도 있고, table전체길이를 지정할 수도 있다.
  • bgcolor는 background-color로 대체한다.
    tr에게는 주지 않습니다! th 혹은 td에 클래스등을 이용해 직접 줍니다!
