position

요소를 원하는 위치에 배치하거나, 화면에 고정시키거나, 다른 요소 위에 겹치게 할 때 사용한다.

① static — 기본값

position을 따로 쓰지 않으면 모든 요소는 static 상태다.

HTML에 쓴 순서대로 왼쪽에서 오른쪽, 위에서 아래로 쌓인다.

② relative

  • 원래 있던 자리를 기준으로 지정한 만큼 이동한다.
  • 눈에 보이는 위치만 바뀌고, 원래 자리(공간)는 그대로 남아있다. 그래서 옆 요소가 밀리지 않는다.
  • 실무에서는 직접 이동 목적보다 absolute의 기준점을 잡거나, z-index를 적용하기 위해 주로 쓴다.

③ absolute

  • 원래 자리에서 완전히 빠져나온다. 그래서 주변에 있는 다른 요소가 그 공간을 차지한다.
  • 움직임의 기준이 필요하다 - 자기 자신의 원래 위치 기준이 아니라, "기준이 되는 부모 영역"을 기준으로 움직인다.
  • 기준 찾는 방법: 부모부터 시작해서 위로 올라가면서 "position이 지정된 요소"를 찾는다. 끝까지 없으면 <html>이 기준이 된다.
  • absolute를 넣으면 해당 요소에 width가 없는경우 내용물만큼 너비가 줄어들기 때문에, width를 지정해 주는것이 좋다
  • ※ "position이 지정된 요소" = relative / absolute / fixed / sticky 중 하나 (static은 해당 없음)

④ fixed

브라우저 화면을 기준으로 위치를 잡는다. 스크롤해도 화면에서 움직이지 않는다.

✅ 실무 사용 예: 항상 보이는 상단 메뉴, 화면 오른쪽 하단 채팅 버튼, 위로가기 버튼

fixed를 넣으면 해당 요소에 width가 없는경우 내용물만큼 너비가 줄어들기 때문에, width를 지정해 주는것이 좋다
특히, 상단에 고정되는 header를 만들경우 width:100%를 주어야 한줄 전체를 차지한다.

※ 오른쪽 하단의 coral 박스가 fixed 예시다. 스크롤해도 같은 자리에 있다.

⑤ sticky

평소에는 일반 요소처럼 있다가, 스크롤하다가 지정한 위치(top: 20px)에 닿는 순간부터 그 자리에 고정된다.

sticky는 부모 영역 안에서만 고정 상태를 유지한다(부모의 범위를 벗어나면 고정이 풀린다).

✅ 실무 사용 예: 스크롤해도 따라오는 사이드바, 테이블 헤더 고정

⚠️ 부모에 overflow 속성이 있으면 sticky가 동작하지 않는다.

⚠️ sticky를 줄 요소가 flex-item이라면, 플렉스 컨테이너에 align-items: flex-start를 설정해야 한다.

⑥ z-index

요소가 겹쳤을 때 어떤 요소가 위에 보일지 순서를 정한다. 숫자가 클수록 위에 표시된다.

⚠️ position이 지정된 요소끼리 겹쳤을때만 동작한다. 기본적으로 포지션된것이 위로 올라간다

※ z-index가 안 먹힐 때 → 해당 요소에 position이 지정되어 있는지 먼저 확인할 것
