01 Swiper란?

Swiper는 이미지나 카드를 좌우(또는 위아래)로 넘기는 슬라이드 기능이 이미 완성되어 배포된 JS 라이브러리예요. 터치 드래그, 자동 넘김, 무한 반복, 점(인디케이터) 동기화까지 다 직접 짤 필요 없이 이미 만들어진 부품을 가져다 쓰고, 겉모습만 내 디자인에 맞게 바꾸는 방식으로 사용합니다.

02 데모 페이지에서 원하는 기능 찾기
1
swiperjs.com/demos 접속
왼쪽 사이드바에 Navigation, Pagination, Autoplay, Space between 등 수십 가지 기능 이름이 나열되어 있어요.
2
검색(Ctrl+K)으로 원하는 기능 찾기 — 예: autoplay
화면 상단의 검색 아이콘(🔍) 클릭 또는 단축키 Ctrl + K → 검색창에 원하는 기능 이름 입력 (예: autoplay)

검색 결과 목록에서 제목 아래 "Swiper Demos"라고 적힌 항목을 클릭하기. 같은 이름이어도 API 문서 등 다른 카테고리가 섞여 나올 수 있으니 꼭 "Swiper Demos" 표시된 것을 선택해야 실제 작동하는 데모 페이지로 이동해요.
💡 "슬라이드가 자동으로 넘어가게 하고 싶다" → autoplay 검색, "화살표로 넘기고 싶다" → navigation 검색, "카드처럼 겹쳐 보이게 하고 싶다" → slides per view 검색 — 원하는 동작을 영어 키워드로 떠올려서 검색하는 습관을 들이면 됩니다.
03 Core 코드 확인하기
🚫 꼭 "Core" 버튼을 눌러서 봐야 해요. React나 Vue를 누르면 우리가 배우는 순수 HTML/CSS/JS 문법과 다른 코드가 나와서 그대로 쓸 수 없어요.
04 코드 복사 & 내 프로젝트에 적용하기
1
head에 들어갈 CSS 링크만 복사
Demo styles(<style>...</style>) 부분은 그 데모 페이지 배경 꾸밈용이라 복사하지 않음.
<!-- Link Swiper's CSS --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@14.0.1/swiper-bundle.min.css" />
2
head 안, 내가 만든 CSS 위에 붙여넣기
복사한 Swiper CSS 링크는 내가 이미 작성해둔 CSS(예: style.css) 보다 위쪽에 붙여넣어야 해요.
<head> ... <!-- Swiper CSS: 먼저 --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@14.0.1/swiper-bundle.min.css" /> <!-- 내가 만든 CSS: 나중에 --> <link rel="stylesheet" href="style.css" /> </head>
💡 CSS는 나중에 불러온 것이 먼저 것을 덮어써요. 내 CSS를 Swiper CSS보다 아래에 둬야, 나중에 화살표·점 색상 같은 걸 내 스타일로 덮어쓸 수 있어요. 순서가 반대면 내가 쓴 CSS가 무시될 수 있어요.
3
body 안쪽 전체(HTML 구조 + JS) 복사
<!-- Swiper --> <div class="swiper mySwiper"> <div class="swiper-wrapper"> <div class="swiper-slide">Slide 1</div> <div class="swiper-slide">Slide 2</div> <div class="swiper-slide">Slide 3</div> <div class="swiper-slide">Slide 4</div> <div class="swiper-slide">Slide 5</div> <div class="swiper-slide">Slide 6</div> <div class="swiper-slide">Slide 7</div> <div class="swiper-slide">Slide 8</div> <div class="swiper-slide">Slide 9</div> </div> <div class="swiper-button-next"></div> <div class="swiper-button-prev"></div> <div class="swiper-pagination"></div> </div> <!-- Swiper JS --> <script src="https://cdn.jsdelivr.net/npm/swiper@14.0.1/swiper-bundle.min.js"></script> <!-- Initialize Swiper --> <script> var swiper = new Swiper('.mySwiper', { spaceBetween: 30, centeredSlides: true, autoplay: { delay: 2500, disableOnInteraction: false, }, pagination: { el: '.swiper-pagination', clickable: true, }, navigation: { nextEl: '.swiper-button-next', prevEl: '.swiper-button-prev', }, }); </script>
4
슬라이드 HTML 구조를 원하는 위치에 붙여넣기
복사한 슬라이드 구조(<div class="swiper mySwiper"> ~ </div>)를 슬라이드가 보여질 위치에 붙여넣기.
<!-- 슬라이드가 보여질 위치 --> <div class="swiper mySwiper"> <div class="swiper-wrapper"> <div class="swiper-slide">Slide 1</div> ... </div> <div class="swiper-button-next"></div> <div class="swiper-button-prev"></div> <div class="swiper-pagination"></div> </div>
5
JS <script> 두 개는 body 맨 끝으로 이동
라이브러리 스크립트와 초기화 스크립트를 </body> 태그 바로 위(body 맨 끝)로 옮겨서 붙여넣기.
<body> ...(다른 콘텐츠들)... <!-- JS는 body 제일 끝으로 이동 --> <script src="https://cdn.jsdelivr.net/npm/swiper@14.0.1/swiper-bundle.min.js"></script> <script> var swiper = new Swiper('.mySwiper', { ... }); </script> </body>
💡 JS를 body 맨 끝에 두는 이유 — HTML 요소들이 먼저 다 그려진 다음에 JS가 실행돼야 .swiper, .swiper-slide 같은 요소를 제대로 찾을 수 있기 때문이에요. 앞쪽(head나 body 중간)에 두면 아직 안 만들어진 요소를 찾으려다 에러가 날 수 있어요.
05 클래스명 변경하기
mySwiper는 데모의 임시 이름이라, 실제 프로젝트에서는 어떤 슬라이드인지 알아보기 쉬운 이름으로 바꾸는 게 좋아요. (예: main_visual_swiper, product_swiper 등 snake_case)
🚫 반드시 두 군데를 다 바꿔야 해요. 한쪽만 바꾸고 한쪽을 안 바꾸면 Swiper가 "이 클래스를 못 찾겠다"며 슬라이드가 아예 작동하지 않아요. 학생들이 가장 많이 하는 실수 중 하나예요.
// ① HTML의 class <div class="swiper main_visual_swiper"> // ② JS의 선택자 var swiper = new Swiper('.main_visual_swiper', {
06 슬라이드 내용 교체하기
swiper-slide 안의 텍스트를 지우고 내 이미지·카드로 바꿔주면 됩니다.
<div class="swiper-slide"> <img src="images/photo_1.jpg" alt="상품 1" /> </div>
💡 이때 swiper, swiper-wrapper, swiper-slide 클래스명은 절대 바꾸지 말고, 내가 추가로 넣는 요소(카드 안 제목/설명 등)에만 snake_case 클래스를 붙이면 돼요. 예: slide_title, slide_desc
07 전체 구조 예시
지금까지 배운 것 — CSS 연결, 클래스명 변경, 슬라이드 내용 교체, body 맨 끝 JS 배치 — 을 전부 적용했을 때 실제 파일이 어떤 모습인지 예시로 보여드릴게요.
<!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8" /> <title>내 프로젝트</title> <!-- ① Swiper CSS는 head에 --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@14.0.1/swiper-bundle.min.css" /> </head> <body> <header>...우리 사이트 헤더...</header> <!-- ② 슬라이드 구조는 원하는 위치에, 클래스명은 mySwiper → product_swiper로 변경 --> <div class="swiper product_swiper"> <div class="swiper-wrapper"> <!-- ③ swiper-slide 안 내용은 내 이미지로 교체 --> <div class="swiper-slide"> <img src="images/product_1.jpg" alt="상품 1" /> </div> <div class="swiper-slide"> <img src="images/product_2.jpg" alt="상품 2" /> </div> <div class="swiper-slide"> <img src="images/product_3.jpg" alt="상품 3" /> </div> </div> <div class="swiper-button-next"></div> <div class="swiper-button-prev"></div> <div class="swiper-pagination"></div> </div> <footer>...우리 사이트 푸터...</footer> <!-- ④ JS 두 개는 body 맨 끝, 선택자도 product_swiper로 통일 --> <script src="https://cdn.jsdelivr.net/npm/swiper@14.0.1/swiper-bundle.min.js"></script> <script> var swiper = new Swiper('.product_swiper', { spaceBetween: 30, centeredSlides: true, autoplay: { delay: 2500, disableOnInteraction: false, }, pagination: { el: '.swiper-pagination', clickable: true, }, navigation: { nextEl: '.swiper-button-next', prevEl: '.swiper-button-prev', }, }); </script> </body> </html>
💡 ①~④ 표시된 순서대로 확인해보면 됩니다 — CSS는 head, 슬라이드 구조는 원하는 자리, 클래스명은 HTML·JS 양쪽 다 동일하게, JS 스크립트는 body 맨 끝. 이 4가지만 지키면 어떤 데모를 가져와도 같은 방식으로 적용할 수 있어요.
08 자주 쓰는 옵션 정리
autoplay: { delay: 5000, disableOnInteraction: false, },
자동 재생. delay는 몇 초 뒤에 다음 슬라이드로 넘어갈지 설정(1000=1초)
speed: 500,
슬라이드가 넘어갈 때 걸리는 전환 속도(1000=1초). 숫자가 작을수록 빠르게, 클수록 천천히 넘어감
loop: true,
슬라이드가 무한 반복되어 돌아가게 만들기
navigation: { nextEl: ".swiper-button-next", prevEl: ".swiper-button-prev", },
화살표가 동작하게 만듦. html에 화살표 관련 태그 추가 후 적용해야 함
pagination: { el: ".swiper-pagination", clickable: true, },
슬라이드 밑의 점(●●●●) 부분이 동작하게 만듦. html에 관련 태그 추가 후 적용해야 함
spaceBetween: 30,
슬라이드 사이에 간격 설정. 기본값은 0
slidesPerView: 3,
한 번에 보이는 슬라이드 개수 설정
slidesPerGroup: 3,
한 번에 넘어가는 슬라이드 개수 설정. 3으로 설정 시 3개가 한꺼번에 넘어감
breakpoints: { 640: { slidesPerView: 2, spaceBetween: 20, }, 768: { slidesPerView: 4, spaceBetween: 40, }, 1024: { slidesPerView: 5, spaceBetween: 50, }, },
창 너비에 따라 다른 개수로 보이게 함. 예) 640px부터 슬라이드 2개·간격 20, 768px부터 4개·간격 40, 1024px부터 5개·간격 50
더 많은 옵션: swiperjs.com/swiper-api
더 많은 데모: swiperjs.com/demos
09 주의사항 체크리스트 참고용
슬라이드가 아예 안 움직여요
HTML의 class명과 JS new Swiper('.클래스명', ...) 안의 선택자가 똑같은지 확인하세요. 오타나 한쪽만 바꾼 경우가 가장 흔한 원인이에요.
화살표나 점이 안 보이거나 눌러도 반응이 없어요
navigation / pagination 옵션을 JS에 추가했는지, 그리고 HTML에 .swiper-button-next / .swiper-button-prev / .swiper-pagination 태그가 있는지 확인하세요. 둘 다 있어야 동작해요.
Swiper is not defined 에러가 떠요
초기화 코드(new Swiper(...))가 Swiper JS 스크립트 태그보다 먼저 실행된 경우예요. JS <script> 두 개를 body 맨 아래에 순서대로(라이브러리 → 초기화 코드) 배치했는지 확인하세요.
한 페이지에 슬라이드를 2개 이상 쓰고 싶어요
각 슬라이드의 클래스명이 서로 겹치지 않게 다르게 지정해야 해요. (예: main_visual_swiper, product_swiper)
